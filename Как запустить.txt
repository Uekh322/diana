СКАЧКИ — ЗАПУСК НА ДРУГОМ КОМПЬЮТЕРЕ

1. На компьютере с 64-разрядной Windows 10 или 11 и .NET Framework 4.7.2 или новее полностью распакуйте ZIP в постоянную папку, в которую можно записывать файлы, например D:\Скачки.
2. Дважды нажмите START.cmd. Если откроется установщик Microsoft SQL Server 2022 LocalDB, завершите установку. Для этого Windows может запросить права администратора. Установщик входит в архив.
3. Дождитесь окна входа. Для демонстрации используйте admin / 123, user / 456 или guest / 111. Подробности — в файле «Роли и вход.txt».
4. Для смены роли закройте программу и снова откройте START.cmd.

При первом запуске программа запуска перенесёт копию рабочей базы из Database в папку Data. При следующих запусках используется эта же база с вашими изменениями. Оставьте папку на прежнем месте и запускайте под той же учётной записью Windows.

Program содержит готовое приложение с фотографиями. Source содержит решение Visual Studio, исходники и пакеты NuGet. Для обычного запуска Visual Studio, SSMS и отдельный запуск SQL-скриптов не нужны.
